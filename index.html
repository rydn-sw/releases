The apps

Voygr

Trip computer for the open road, whether you are behind the wheel of a van, an RV, or a big rig. Speed, heading, elevation and trip logs, with speed-limit signs from an on-board database. At 60 miles per hour you travel 88 feet in one second — so Voygr is designed to be glanceable in a fraction of a second, keeping your eyes on the road.

Setting it up, and what's new

The first time you open it

  1. Allow Location — While using the app.
  2. Put the phone in landscape in its mount. The cockpit layout assumes it.
  3. Tap LOAD on the speed-limit sign, then Download the state or states you drive in. This is a one-time download — after that the speed limits work with no signal at all.

What's new

  • A PLAYER key that switches straight to Rydn Player.
  • Thumbnails in settings, a GPS spike filter, and layout fixes.

Worth knowing

  • The PLAYER key at the bottom right stays gray until Rydn Player is installed. That is expected, not a fault. To hide it: Setup → Switch to other app(s) button.

Rydn Player

Large-button music player for the road. Oversized controls you can hit using only peripheral vision while your eyes stay on the road. Song ratings saved to a folder you choose.

⬇ INSTALL Rydn Player V1.8

Latest known: Rydn Player V1.8 · published 2026-09-21

Setting it up, and what's new

The first time you open it

  1. Tap 📂 PICK MUSIC FOLDER and choose your music folder — subfolders are included automatically. Tap Allow / Use this folder when Android asks; the choice is remembered.
  2. Choose a folder for the ratings file if you want your star ratings kept.
  3. Turn the phone to landscape. The deck layout — transport keys, HOLD bar and ratings — is the screen the app is built around.
  4. Optional, under ⚙ Settings: rating filter and weights, Sequential or Shuffle, whether unrated songs play, which folder or database to draw from, and haptics.

What's new

  • The home-screen icon caption now reads Playyr, so it is no longer truncated.
  • Import ratings (⚙ Settings) restores ratings from a CSV you exported earlier.
  • Long files can hold section ratings — the stars follow the playhead.
  • The volume number tracks every control, including the phone's hardware keys.

Worth knowing

  • Back up your ratings: ⚙ Settings → share the dated ratings CSV, then e-mail it to yourself or save it to Drive from the share sheet.
  • VOL + and VOL − move the real Android media volume — the same level the hardware keys move, and a Bluetooth speaker follows it.
  • Installing a new version over an older one keeps your ratings, music folder and settings.
  • Install Voygr too and each app gets a key that jumps straight to the other.

DoStack

To-do lists that sync between your phone and any browser. Works offline and catches up later; no VPN needed.

⬇ INSTALL DoStack v22

Latest known: DoStack v22 · published 2026-09-27

Or use it in a browser — nothing to install: https://158-101-7-190.sslip.io/
The address is the same for everyone. Paste your key in the ⚙ gear menu to see your own list.

About syncing. Sync is optional — without a key, DoStack stays on that one device. Turn it on and your lists are stored on a small server in Oracle Cloud so your phone and browser stay in step. The connection is encrypted, and your key is what keeps other users out of your list. Save the key when it is shown; it is not shown again. Your lists are not encrypted against us: we run the server and could in theory read what is on it, so treat DoStack as a to-do list, not a place for passwords or private personal details.

Setting it up, and what's new

The first time you open it

  1. Start using it straight away — type in the bar at the top and the item is saved. Installing does nothing on its own.
  2. To see the same list on another phone or browser you need a key. Either paste one you were given into the ⚙ gear menu and press SET, or tap START A NEW LIST to make one on the phone.
  3. A new key is shown once. Save it somewhere — it is not shown again.
  4. No key? It still works as a private list on that device and says SYNC has no KEY. That is a normal state, not an error.

What's new

  • START A NEW LIST in the gear menu makes your own key on the phone, so you no longer have to be given one.
  • The web address is inside the app now: ⚙ gear → OPEN ON ANY DEVICE, with the address as a link plus COPY and COPY KEY. Copying can fail inside the phone app; when it does the app says so, and you can select the text by hand.
  • Archive (⚙ gear) keeps everything you finish or delete, with the dates it was added and closed, and a RESTORE button. Export archive saves the whole history as a spreadsheet — that works from a browser, and may not work inside the phone app.
  • Deleting a stack asks first, and its items move to Main, so nothing is lost.
  • Color and move buttons are on every item. Move is how you send an item to another stack.

Worth knowing

  • Everything works offline. Sync catches up by itself when the network comes back.
  • Treat your key like a password. It stays in whatever phone or browser you paste it into, so don't paste it on a shared or public computer.
  • Upgrading: just install over the old version. Your items, your key and your settings are kept, and there is nothing to change in settings afterward.

Setting it up, and what's new

The first time you open it

  1. Tap Create your first plan and write one small if-then: “After I finish dinner, I will clear one kitchen surface.” Small is the point.
  2. There is no account and nothing to sign in to.
  3. Reminders are on from the start, so it asks permission for notifications the first time you open it. You can turn them off in Settings whenever you like.

What's new

  • A link at the top, The actual science of building habits — the real research behind the app, with citations, and how it differs from the fake-expert claims these apps usually make.

Worth knowing

  • Everything stays on the phone. Nothing is uploaded, and there is no password or key.
  • The reference links open in your web browser, which is expected.
  • Reminders only arrive from the installed app.

How to install — any of them

  1. Tap a blue button above — on the phone. Chrome asks "Download file?" and warns the file may harm your phone — tap Download. The warning is expected for any app that doesn't come from the Play Store.
  2. When the download finishes, tap Open file.
    The Open file button disappears after a few seconds. If it's gone, no file manager app is needed — in Chrome tap the ⋮ menu (top right) → Downloads → tap the file. Or use any file manager: Android's built-in Files app (Files by Google on Pixel, My Files on Samsung) → Downloads → tap the .apk.
  3. When asked "Install this app?", tap Install.
  4. When "App installed" appears, tap Open. Installing over an older copy keeps your data.

First time on a new phone

  1. If Android says the browser or file manager isn't allowed to install unknown apps: tap Settings → turn ON Allow from this source → Back, then tap the file again.
    Screenshot — Allow from this source toggle
  2. Google Play Protect may block the install ("App blocked to protect your device"): tap More details, then Install anyway.
  3. If asked "Send app for a security check?", tap Don't send or Send this time — either way the install continues.
